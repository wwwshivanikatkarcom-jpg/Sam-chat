# Sam Chat

बहुत हल्की प्राइवेट चैट वेबसाइट। कोई फ्रेमवर्क नहीं, सिर्फ साधारण HTML और JavaScript, ताकि कम डेटा और पुराने फ़ोन पर भी चले।

## सेटअप

1. Firebase Console में नया प्रोजेक्ट बनाओ।
2. Authentication में Email/Password चालू करो।
3. Realtime Database बनाओ और Rules में database.rules.json पेस्ट करो।
4. Project settings से Web API key लो और Database URL लो, फिर index.html के ऊपर CFG में भरो।
5. Authentication में हाथ से ओनर अकाउंट बनाओ: ईमेल sam@sam.chat और 10 अंक का पासवर्ड।
6. firebase login, फिर firebase init (Hosting और Database चुनो, public फोल्डर वही रखो जहाँ index.html है), फिर firebase deploy।
7. कोड GitHub पर push करो।
8. वेबसाइट खोलो, यूज़रनेम sam और अपने पासवर्ड से लॉगिन करो, Admin टैब से यूज़र जोड़ो।
9. पासवर्ड रीसेट चालू करने के लिए functions फोल्डर deploy करो (Blaze प्लान), फिर उसका URL index.html में CFG के resetUrl में भरो। जब तक ये नहीं भरा, रीसेट काम नहीं करेगा।

## ज़रूरी बातें

- लॉगिन सेव नहीं होता। रिफ्रेश करने पर फिर लॉगिन पेज आता है।
- मैसेज हर 3 सेकंड में अपने आप आते हैं, रिफ्रेश की ज़रूरत नहीं।
- देखा हुआ मैसेज उस यूज़र की स्क्रीन से 2 घंटे बाद गायब होता है। सब देख लें और 2 घंटे बीत जाएँ तो डेटाबेस से भी मिट जाता है।
- ये एंड-टू-एंड एन्क्रिप्टेड नहीं है। Firebase प्रोजेक्ट का मालिक डेटाबेस में मैसेज देख सकता है। नियम सिर्फ बाकी यूज़र्स को रोकते हैं।
- यूज़र Remove करने पर उसका चैट एक्सेस बंद हो जाता है, लेकिन उसका लॉगिन अकाउंट Firebase Console के Authentication में से खुद डिलीट करना होगा।
- नोकिया 3310 जैसे फ़ोन पर: Firebase सिर्फ HTTPS देता है। जो ब्राउज़र HTTPS नहीं खोल सकते (बहुत पुराने मॉडल) उन पर नहीं चलेगा। Opera Mini वाले नए 3310 पर चलना चाहिए, पर असली फ़ोन पर आज़माकर देख लेना।
- दस अंक का पासवर्ड अंदाज़े से टूट सकता है। Firebase खुद गलत कोशिशें रोकता है, फिर भी पासवर्ड आसान मत रखो।
